# ROCKEYE Entitlement Engine

**Classification:** PRIVATE CORE REPOSITORY — PROPRIETARY INTELLECTUAL PROPERTY  
**Owning Domain:** Platform / SaaS Monetization & Licensing  
**Scope:** Tenant subscription tiers, module feature flags, and capacity quota enforcement  

## 1. Overview

The Entitlement Engine governs multi-tenant SaaS feature access:
1. **Tier Management:** Standard (Single Mill), Enterprise (Multi-Mill), Conglomerate (Multi-Company).
2. **Quota Checks:** Active mill counts, processing capacity caps, and user seat limits.
3. **Module Licensing:** Feature gating for advanced MES routing, automated weighbridge hardware integration, and LIMS integrations.
