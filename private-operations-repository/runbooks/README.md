# ROCKEYE Operational Runbooks

**Classification:** PRIVATE OPERATIONS REPOSITORY — CONFIDENTIAL  
**Owning Domain:** Operations / SRE & Support  
**Scope:** Step-by-step procedures for mill disaster recovery, database failover, schema migrations, and high-severity incidents  

## Runbook Directory

1. `disaster-recovery.md`: Point-in-time recovery (PITR) procedures, RTO (< 15 mins), RPO (< 1 min), and offline weighbridge operation continuity.
2. `incident-response.md`: Sev-1 (mill offline / weighbridge halted) to Sev-4 escalation procedures, war room setup, and RCA protocols.
